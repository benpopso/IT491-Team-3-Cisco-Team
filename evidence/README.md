# Test Evidence

Store evidence for acceptance tests T-01 through T-15 here.

Create a folder when work begins on a test, such as `T-03-port-security`. Each test folder should contain:

- A short description of what was tested
- Normal-condition evidence when applicable
- Abnormal-condition evidence when applicable
- The observed result
- Any limitation or failed result

Use real test results only. Do not replace or alter evidence to make a failed test appear successful.
